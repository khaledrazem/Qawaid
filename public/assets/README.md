# Background overlay images

To use the same background pattern images as the qawaid-ui repo, copy these two files from the UI repo's assets (or Figma exports) into this folder:

- `pattern1.png` — from qawaid-ui: `2c2213ef845c670961b84771c770099a43c2f192.png`
- `pattern2.png` — from qawaid-ui: `d152a7d9d0f1bfa1d731c6502705a9d0fb91683d.png`

Rename them to `pattern1.png` and `pattern2.png`. If these files are not present, the app falls back to an SVG pattern.
