Question type
MCQ: Multiple choice question
MCQ-fillin: Multiple choice question that highlights a missing word in a sentence and options are not limited to a category, but must include correct definition
Word-in-sentence: select a word from the prompt
Letter-in-sentence: select a letter from the sentence
Yes-or-No: ask the user mcq of yes or no, difference is this can be selected for a prompt even if the category doesn't match the question
Visual-mcq: shows an image on the screen and asks a mcq question about it, image could have text under it
Fill-in-sentence: Type in a missing word in a sentence to satisfy partnering question, question generator will have to pick a prompt and display it without the chosen definition, then the user has to type that in and the app will compare user input with the original word in the prompt (provide virtual arabic keyboard)
Letter indices are raw string indices; No restrictions in code, admin should know what to avoid
Transformation: definitions have a new column called indicator, it is a substring that should exist in the word in the prompt, what this question type does is it displays the prompt with the chosen word highlighted, but removes this substring from the word, and the question will usually ask the user to enter the original word as is, user input will be compared exactly to the original word before removal of indicator substring. A virtual keyboard will be needed and a definition could have multiple substrings. Also the new field is optional, so when this question type is pulled, it should only be picked for words that have a non null indicator field.
Drag-and-match:user is shown a sentence where every word is draggable, definitions pulled from the category each have a field (those of which that exist in the prompt), the user has to drag the correct words to the correct categories, once all words are dragged correctly it should automatically end the question
Questions
Extra details:
- multiple choice will show 3 to 4 possible options that are randomly selected from the pool of possible answers, must be including the actual correct answer
